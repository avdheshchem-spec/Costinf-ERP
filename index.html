        Load Backup from Google Drive

        A plain Google Drive share link can't be fetched directly by a webpage (Google blocks it) — this uses Google's official Drive API instead, which needs a free API key. One-time setup, about 3 minutes: show me how.
        1. Go to console.cloud.google.com → create a project (or use an existing one).
        2. Left menu → APIs & Services → Library → search "Google Drive API" → click Enable.
        3. Left menu → APIs & Services → Credentials → Create Credentials → API key. Copy it.
        4. (Recommended) Click the new key → under "API restrictions" choose Restrict key → tick only Google Drive API → Save.
        5. In Google Drive, right-click your backup JSON file → Share → change to "Anyone with the link" → Viewer. This API key approach only works for files shared this way (it can't read private files).
        Saved locally in this browser after first use — you won't need to re-enter it next time.
